PYTHON PROGRAMMING TASKS — STARTER PACK

Included projects:
1. task1_hangman.py — text-based Hangman game
2. task2_stock_portfolio_tracker.py — sample stock portfolio calculator
3. task3_file_automation.py — moves JPG/JPEG files between folders
4. task4_basic_chatbot.py — rule-based chatbot

Requirements:
- Python 3.9 or newer recommended.
- No external packages are required.

How to run:
1. Download and extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open a terminal in VS Code.
4. Run one file at a time, for example:
   python task1_hangman.py

For Task 3:
- Run task3_file_automation.py once to create source_images and organized_images folders.
- Put test JPG/JPEG images inside source_images.
- Run the script again.
- It moves images into organized_images. Test with copies of files, not your only originals.

Notes:
- Stock prices are hardcoded sample values, not live market prices.
- These are beginner-level examples. Review and customize the code before submitting.
